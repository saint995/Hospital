Unordered list is a list of items in which the order of the items does not matter. It is created using the <ul> tag, and each item in the list is represented by the <li> tag.

Example of an unordered list:

  • Betroot
  • Milicent
  • Chirchir
  • Bootstrap
  • potato
  • Ginger
  • Radish
